# 처음에는 "개념이면 뺀다" 로 갈랐는데 그건 틀린 기준이었다.
# 개념이라서 빼는 게 아니라 **모두가 갖다 붙일 수 있어서** 빼는 것이다.
#
#   물어볼 것 하나 — **"이걸 다룰 줄 아느냐"에 사람마다 답이 갈리는가.**
#
#   갈린다  → 남긴다.  형태가 개념이어도 상관없다.
#             `Transformer` `CNN` `RAG` `LoRA` 는 구조·기법이지만 구현에 실력 차가 난다.
#             AI 쪽에서는 이런 것을 **구체적으로 다룰 수 있느냐**를 묻는다.
#   안 갈린다 → 뺀다.
#             `CI/CD` `MSA` `AI/ML` 은 안 한다고 말하는 회사가 없다.
#             `GitHub` `Slack` 은 계정만 있으면 된다. `MCP` 는 개나 소나 쓴다.
#
# 그래서 `Transformer` 는 남고 `CI/CD` 는 빠진다. 둘 다 형태는 개념이다.
# 가르는 것은 **깊이**다 — 익히는 데 시간이 드는가, 잘하고 못하고가 있는가.
#
# 이 파일은 tech_blocklist.txt 와 다르다.
#   blocklist  : 진짜 기술이지만 **산문에서 오탐**이 되는 이름 (Lambda, Storm, S3)
#   rejected   : 애초에 **기술스택이 아닌** 이름
