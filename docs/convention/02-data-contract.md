# 데이터 계약 — CSV 13컬럼

**모든 사이트가 이 스키마를 지킨다.** 그래야 CSV 를 합쳐 볼 수 있다.
스키마의 단일 출처는 `job_sites/_common/store.py` 의 `COLUMNS` 다.

```
기업명, 공고명, 마감일, 지원자격, 우대사항, 경력, URL, 연봉, 기술스택, 근무지, 사이트명, 최초수집일, 최종확인일
```

## 각 칸

| 컬럼 | 채우는 규칙 | 없으면 |
|---|---|---|
| 기업명 | 회사 이름 그대로 | 빈 문자열 |
| 공고명 | 공고 제목 그대로. 한 줄로 누른다 | 빈 문자열 |
| 마감일 | `YYYY-MM-DD`. 시각은 자른다 | `상시채용` |
| 지원자격 | 공고 원문 그대로. 요약하지 않는다 | 빈 문자열 |
| 우대사항 | 공고 원문 그대로 | 빈 문자열 |
| 경력 | `신입` / `신입~3년` / `3~10년` / `5년 이상` / `경력무관` | `경력무관` |
| URL | 공고 주소. **행의 키다** | 행을 만들지 않는다 |
| 연봉 | 사이트가 주면 채우고, 안 주면 **빈칸** | 빈 문자열 |
| 기술스택 | 표준 표기, comma 구분 | 하나도 없으면 **행을 뺀다** |
| 근무지 | `시도 구 상세주소` | 빈 문자열 |
| 사이트명 | `wanted` `saramin` … 고정값 | — |
| 최초수집일 | `YYYY-MM-DD`. **병합이 채운다** | — |
| 최종확인일 | `YYYY-MM-DD`. **병합이 채운다** | — |

## 세 가지 규칙

### 사이트에 없는 값도 칸은 남긴다

Wanted 는 연봉을 아예 공개하지 않는다. 그래도 컬럼을 빼지 않고 **빈 문자열**을 넣는다.
CSV 를 합칠 때 모양이 어긋나면 안 되기 때문이다.

값이 왜 비었는지는 **실행이 끝날 때 알린다.**

```
HOPE_ANNUAL_SALARY(3300)는 적용하지 않았습니다 — Wanted 는 공고에 연봉을 공개하지 않습니다
```

### 이력 두 칸은 사이트가 만들지 않는다

`최초수집일` `최종확인일` 은 한 실행 안에서 알 수 없는 값이다. 쌓아 둔 파일과 맞대야 나온다.
그래서 `record.to_row()` 는 앞 11칸만 만들고, `store.merge()` 가 나머지를 채운다.

### 원문을 요약하지 않는다

`지원자격` `우대사항` 은 공고에 적힌 그대로 넣는다. 줄바꿈도 그대로다.
읽는 사람이 판단할 재료를 코드가 미리 줄이면 안 된다.

## 누적 — 덮어쓰지 않는다

파이프라인은 주기로 돈다. 매 실행이 파일을 갈아엎으면 **마감돼 내려간 공고가 흔적 없이
사라진다.** 실측으로 몇 시간 만에 공고 하나가 `status=close` 로 내려가는 것을 봤다.

공고 URL 을 키로 병합한다.

| | 어떻게 |
|---|---|
| 처음 본 공고 | 추가. `최초수집일` = `최종확인일` = 오늘 |
| 이번에도 본 공고 | 내용은 최신으로, `최종확인일` 만 오늘. **`최초수집일` 은 지킨다** |
| 이번에 안 보인 공고 | 남긴다. `최종확인일` 이 멈춰서 내려갔음이 드러난다 |
| **30일 넘게 안 보인 공고** | **뺀다** (`store.RETENTION_DAYS`) |

보존 경계는 정확히 30일이다 — 30일째는 남고 31일째부터 뺀다.

**날짜를 모르는 행은 지우지 않는다.** 이력 컬럼이 없던 시절 파일에서 올라온 행이 그렇다.
모르는 것을 오래됐다고 단정하면 지울 이유가 없는 공고를 지운다. 오늘이 언제인지 못 읽는
경우에도 만료 판단 자체를 하지 않는다.

## 쓰기

쌓는 구조라 파일 하나에 이력이 전부 들어 있다. 한 번 깨지면 되돌릴 수 없다.

- **원자적 쓰기** — 같은 디렉터리 임시 파일에 다 쓰고 `os.replace`. 도중에 죽어도 이전 파일이 남는다
- **실행 락** — cron 이 겹쳐 두 실행이 읽고-고치고-쓰면 한쪽 결과가 조용히 사라진다

둘 다 `_common/` 이 해 준다. 사이트는 `merge()` `write_csv()` `run_lock()` 을 부르기만 한다.

## 인코딩

`utf-8-sig` (UTF-8 BOM). 엑셀에서 한글이 안 깨진다.

## 산출물은 저장소에 넣지 않는다

`<사이트>/csv/` 는 `.gitignore` 대상이다. **사람마다 스크랩 대상이 다르다** —
남의 조건으로 뽑은 CSV 를 받을 이유가 없다. 클론한 사람은 자기 `.env` 로 직접 돌린다.
