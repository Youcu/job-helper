# 낱말 뉘앙스 판정

```bash
python3 src/nuance.py
```

**낱말이 걸렸다고 다 결격은 아니다.** 거르기가 낱말만 보고 자르던 것을 여기로 옮겼다.

```
csv/merged_filtered.csv  ──▶  csv/merged_nuance.csv    남은 공고
                         +    csv/nuance_report.csv    판정 전량 (남긴 것까지)
```

## 왜 필요한가 — 같은 낱말이 정반대를 뜻한다

실측(2026-09-22, 최종 46행 중 본문에 금칙어가 있는 11행)으로 이렇게 갈렸다.

| 글 | 뜻 |
|---|---|
| `단순 **SI**가 아닌 자사 플랫폼 중심으로` | SI 를 **부정**한다 |
| `2,000개 이상의 **고객사**를 유치했으며` | 자사 플랫폼의 **고객 수** 자랑 |
| `**고객사** 상위 시스템(MES·ERP) 연동 API` | 자사 제품이 **연동하는 대상** |
| `※ 산업기능요원 **보충역** 지원 가능합니다` | 요구가 아니라 **혜택 안내** |
| `모집분야 시스템통합(**SI/SM**)` | 진짜 SI 업체 |
| `**SI** 프로젝트 웹/업무시스템 유지보수` | 진짜 |
| `GIS 기반의 **SI** 및 통합 솔루션 IT기업` | 회사소개에서 **자기가 SI 라고 말한다** |
| `근무형태: **고객사** 상주` | 진짜 상주다 |
| `**[병역특례]** Android Developer` | 병역특례 **전용** 공고 |

**낱말만 보고는 못 가른다.** 규칙을 더해도 다음 형태에서 또 뚫린다. 그래서
**좁히는 일은 코드가, 판정은 모델이** 한다 (`src/career.py` 와 같은 모양).

## 본문까지 본다

거르기는 `공고명`·`지원자격`·`우대사항` 셋만 봤다. 회사 이름과 지역명이 낱말을 품어
근거 없이 자르게 되기 때문이다. 그래서 **회사소개에서 자기가 SI 기업이라고 말해도
안 걸렸다.**

여기서는 `csv/bodies.jsonl` 의 본문까지 넣는다. 후보는 늘지만 **자르는 것은 모델**
이므로 후보가 곧 삭제가 아니다.

**같은 낱말이 칸과 본문 둘 다 있으면 칸 쪽만 싣는다.** 무게가 큰 쪽이 칸이다 —
자격요건의 `SI` 는 그 자리의 조건이고, 회사소개의 `SI` 는 회사의 업이다.

## 무엇을 하고, 무엇을 안 하나

| | |
|---|---|
| **한다** | 낱말이 걸린 공고만 모델에 묻는다 · **남긴 것까지 전량 보고에** |
| **안 한다** | 낱말만으로 자르지 않는다 · **애매하면 안 뺀다** · 못 물어본 것을 결격으로 읽지 않는다 |

**못 물어본 것을 결격으로 읽으면 안 된다.** 여기가 뚫리면 모델이 잠깐 막힌 날
목록이 통째로 준다. 판정 실패는 **남기고** 보고에 적는다.

**남긴 것도 전량 적는다.** 낱말이 걸렸는데 남겼다는 것은 사람이 되짚어야 할 판단이다.
안 적으면 왜 남았는지 알 수 없고, 판정이 느슨해져도 드러나지 않는다.

## 시범 판정 — 실측 8건 전량

```
남김   엘리스              병역특례 문구는 '지원 가능합니다'라는 혜택 안내이지 전용 공고가 아니다
남김   삼익THK(주)         고객사 상위 시스템 연동은 자사 RCS 제품이 연동하는 대상을 가리킨다
남김   (주)유비즈           '단순 SI가 아닌 자사 플랫폼 중심'처럼 부정하는 문장이다
남김   (주)고워드           자사 플랫폼의 고객 수(2,000개 이상)일 뿐이다
피함   (주)제타럭스시스템      회사소개에서 스스로를 GIS 기반 SI 및 통합 솔루션 IT기업이라 밝힌다
피함   (주)우리아이시티       모집분야가 시스템통합(SI/SM)이고 담당업무도 SI/SM 관련 업무다
피함   수테크시스템즈(주)      담당업무 자체가 SI 프로젝트 구축·유지보수다
피함   (주)파워인포텍         근무형태가 '고객사 상주'로 명시되어 있다
```

**8건 전부 사용자 판정과 일치했다.**

## 규칙을 고치면 `RULES_VERSION` 을 올려라

안 올리면 고친 프롬프트가 이미 판정된 공고에는 영영 안 먹는다 — `src/career.py` 에서
실제로 겪었다.

## 종료 코드

```
0  정상
1  입력이 없거나 claude 명령을 못 찾음
3  이미 돌고 있다
```

`claude` 가 없으면 **거르지 않고 통과시키는 대신 멈춘다.** 통과시키면 걸렀다고
믿는데 안 걸린 파일을 받는다.
